✅ 1. MODUL PENGELOLAAN STOK CABANG

🔹 Fungsi Utama:
•Sistem menyimpan data stok barang di database
•Sistem menampilkan stok real-time
•Sistem update stok otomatis dari transaksi

🔹 Functional Requirements:
Admin/Kepala Cabang dapat:
Menambah data barang
Mengubah data barang
Menghapus data barang
Sistem dapat:
Menyimpan data barang (nama, kode, harga, stok)
Menampilkan stok barang per cabang
Mengurangi stok saat terjadi penjualan
Menambah stok saat ada pembelian barang
Sistem menyediakan:
Pencarian barang
Filter stok (tersedia / habis)


2. MODUL KEEP BARANG (RESERVASI)

🔹 Fungsi Utama:

Barang disimpan sementara untuk pelanggan sebelum dibayar

🔹 Functional Requirements:
Kasir dapat:
Menyimpan barang (keep)
Menentukan batas waktu keep
Sistem dapat:
Menyimpan data keep (barang, pelanggan, waktu)
Mengurangi stok sementara
Mengembalikan stok jika waktu habis
3.Sistem memiliki:
•⏱ Timer (Intermediate Timer Event)
→ untuk batas waktu keep
Gateway:
Apakah waktu keep habis?
Ya → stok dikembalikan
Tidak → lanjut ke pembayaran

⸻

✅ 3. MODUL PROSES PENJUALAN

🔹 Fungsi Utama:

Proses transaksi dari pilih barang sampai pembayaran

🔹 Functional Requirements:

👤 Pelanggan:
•Memilih barang
•Memilih metode pembayaran (tunai / transfer)

👨‍💼 Kasir:
•Login ke sistem
•Input barang ke sistem
•Memproses transaksi

🖥 Sistem:
•Mengambil data barang dari database
•Menghitung total harga
•Mengelola pembayaran
•Menyimpan transaksi


🔹 DETAIL ALUR (PENTING – sesuai BPMN kamu):

1. Login
•Kasir login ke sistem

2. Input Barang
•Kasir input barang
•Sistem cek stok

3. Gateway:

Stok tersedia?
•Tidak → tampilkan “stok habis”
•Ya → lanjut

⸻

4. Pilih Metode Pembayaran

💵 Tunai:
•Kasir menerima uang
•Sistem mencatat pembayaran
•Kasir klik cetak struk

⸻

💳 Transfer:
•Kasir memberikan nomor rekening

🔁 Sistem:
•Menunggu pembayaran

⏱ Intermediate Event:
•Menunggu konfirmasi transfer

Gateway:

Pembayaran sudah masuk?
•Belum → tetap menunggu
•Sudah → lanjut

⸻

Setelah pembayaran:
•Sistem konfirmasi pembayaran
•Kasir klik cetak struk
•Sistem simpan transaksi
•Sistem update stok

⸻
